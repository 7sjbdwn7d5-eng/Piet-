# Themen-Warteschlange
**Aktuelles Format (Wunsch des Nutzers): „Ein Tag als …" und „Die letzten Stunden von …"** – Uhrzeiten statt Zeitsprünge.
Jeden Tag wird das oberste offene Thema produziert und abgehakt. Neue Ideen einfach unten anhängen.

- [x] Ein Tag als Gladiator im alten Rom → `gladiator/`

- [ ] Ein Tag als Pirat in der Karibik um 1700 (gewählter Kapitän, Skorbut)
- [ ] Ein Tag als Astronaut auf der ISS (16 Sonnenaufgänge, Urin wird Trinkwasser)
