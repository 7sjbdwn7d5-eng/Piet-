# Gleichnis-Format: „Der Elefant – Teil 2: Ein kleiner Ruck"

**Video:** `elefant2_final.mp4` – 33,9 s, 1080×1920, 30 fps. Erzähler vorerst Ersatzstimme; Sprecher-Fassung nach Upload.
Stil wie `elefant/` (Raum mit Hängelampe → Schwarz mit Strichmännchen, ein Wort groß, Zähler, Schild „GLEICHNIS").

## Ablauf
Alter Elefant im roten Kreis („Tage im Kreis" bis 7.300) → Licht flackert, Tage vergehen → junger Elefant kommt (nie ein Seil gespürt) →
läuft über die rote Linie (Linie glüht kurz), nichts passiert → der Alte schaut nach → kleiner Schritt → Ruck → **Seil reißt**, Pflock kippt →
der Alte geht hinaus → SCHWARZ: „ganzes Leben" (Berg, durchgestrichen) → Lied singen („Kleine Rucke 1") → Aufgabe rechnen (2) →
Seil reißt (3) → gelbe Figur läuft vor, weiße folgt → „Was ist dein erster kleiner Ruck?"

## Sprechertext für ElevenLabs (eleven v4, ruhig)
```
Teil zwei. Der Elefant steht immer noch im Kreis. Jeden Tag.
Bis eines Morgens ein junger Elefant kommt. Er hat nie ein Seil gespürt.

Der Alte schaut ihm nach. Ein kleiner Schritt. Ein Ruck. Das Seil reißt.
Du musst nicht dein ganzes Leben auf einmal ändern.
Sing ein Lied, nur für dich. Rechne eine Aufgabe. Ein kleiner Ruck reicht.
Und manchmal brauchst du jemanden, der vorläuft.
Was ist dein erster kleiner Ruck?
```
